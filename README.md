# Liquid Glass Dock Maker

Free, open-source tool that adds a liquid glass dock to any phone wallpaper. Runs fully in your browser: no upload, no login, no server.

**Features:** liquid refraction at the edges, blur, saturation, darkness, shadow, corner roundness, dock size and position, optional white frost and edge light, English and Bengali UI, works offline as a PWA.

**How to use:** open the site, choose your original wallpaper (without a dock or icons), adjust the sliders, press *Save image*, then set the PNG as your wallpaper.

**Run locally:** open `index.html` in a browser, or serve the folder with any static server.
